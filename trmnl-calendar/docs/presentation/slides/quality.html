Quality and operations

Trust it enough to forget about it

Tests at three levels

Pure-logic unit tests, golden-image render checks, and contract tests against a fake display server.

CI on every pull request

Lint, format, tests and a container build must pass. Nothing goes straight to the main branch.

Backups you can restore

Daily backups and one before every database migration, plus a restore tool and a practised restore drill.

An honest health check

It reports the database, the last backup and the scheduler, and says “off” when pushing is off instead of pretending.

The repository is public, so the pipeline rules are strict: no secrets in the repo, third-party automation pinned to exact versions, minimal permissions. Mention the restore drill: a backup you have never restored is only a hope.
