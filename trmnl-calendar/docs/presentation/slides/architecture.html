Terminus

Display

TRMNL OG, e-paper

The app owns the data and the drawing.

Terminus is swappable: it only delivers a PNG.

Nothing leaves the home network.

Walk left to right. The app is one container: web pages and a JSON API, a SQLite file, a renderer that produces the image, and a publisher that tells Terminus when there is a new picture. Terminus keeps the picture and the display collects it on its own schedule. If Terminus were replaced, only the publisher module would change.
